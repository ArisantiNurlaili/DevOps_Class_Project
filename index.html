Tahapan DevOps & Toolchain

  • • DevOps Toolchain

    Kumpulan alat (tools) terintegrasi yang digunakan untuk mengotomatisasi tahapan pengembangan, pengujian, hingga deployment perangkat lunak.

  • • Plan (Perencanaan)

    Tahap awal untuk menentukan tujuan proyek, merumuskan ide, membuat backlog, dan menyusun manajemen tugas atau fitur aplikasi.

  • • Create (Pembuatan/Coding)

    Proses penulisan kode program dan pembangunan komponen aplikasi oleh para developer menggunakan bahasa pemrograman tertentu.

  • • Verify (Pengujian/Verifikasi)

    Tahap pengujian kualitas kode secara otomatis (seperti menggunakan linter atau unit test) untuk memastikan tidak ada *error* atau *bug*.

  • • Package (Pengemasan)

    Proses menggabungkan kode aplikasi beserta dependensinya ke dalam bentuk paket siap rilis (seperti kontainer Docker).

  • • Release (Rilis)

    Tahap penyaluran versi aplikasi yang sudah stabil agar siap untuk didistribusikan ke lingkungan produksi atau server.

  • • Configure (Konfigurasi)

    Pengaturan infrastruktur, environment server, dan manajemen sistem pendukung agar aplikasi dapat berjalan dengan optimal.

  • • Monitoring (Pemantauan)

    Proses pengawasan performa aplikasi dan server secara *real-time* untuk mendeteksi masalah atau gangguan secara cepat.
